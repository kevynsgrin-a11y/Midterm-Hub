The civic calendar should be public infrastructure.

Plumbline is a curation-first election calendar built to answer a deceptively difficult question: when is the next election, and where did that date come from?

Election information is fragmented across state calendars, local notices, PDFs, and changing web pages. This project turns those records into a consistent public reference without hiding uncertainty or provenance.

It is not an election authority. Readers should always confirm voting requirements with their state or local election office.
